# Dhruva React homepage
Run `npm install` then `npm run dev` in this folder.
Built with React, HTML, CSS and JavaScript using Vite.
The street illustration is in `public/dhruva-street.png`.
The two sample hover hotspots are approximate; adjust `.shop` and `.gate` in `src/App.css` to align them exactly. For true red-to-white recoloring of individual drawn objects, convert the illustration into separate SVG paths.
